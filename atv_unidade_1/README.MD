# Análise de Dados de Acidentes 🚦

Este projeto utiliza a base de dados da **PRF (Polícia Rodoviária Federal) - Datatran 2025** para realizar uma atividade de **análise de dados em Excel**.  
O objetivo é explorar estatísticas de acidentes, causas, severidade e distribuição em rodovias brasileiras.

## 📊 Estrutura do Projeto
- **Sheet1** → Base de dados original (acidentes, causas, tipo, mortos, etc.)
- **MEDIDAS** → Cálculos com fórmulas e uso do `PROCV` para médias e contagens.
- **Gráficos** → Visualizações como:
  - Situação dos envolvidos nos acidentes
  - Rodovias com mais acidentes
  - Índice de severidade e sobreviventes

## 🛠️ Técnicas Utilizadas
- Fórmulas do Excel (`AVERAGEIF`, `PROCV`, contagens e médias)
- Organização em diferentes **abas (sheets)**
- Criação de **gráficos comparativos** para análise visual

## 🚀 Objetivo
Demonstrar como aplicar conceitos de **análise de dados** em planilhas, transformando uma base bruta em informações úteis para interpretação e tomada de decisão.
