# 🚦 Relatório de Acidentes Rodoviários – PRF 2025

## 📖 Sobre o Projeto

Este projeto tem como objetivo realizar uma análise exploratória dos dados de acidentes rodoviários registrados pela Polícia Rodoviária Federal (PRF) durante o ano de 2025.

A análise foi desenvolvida como parte da **Unidade 5.2 – Frequências, Rankings e Séries Simples**, utilizando técnicas estatísticas descritivas para identificar padrões, fatores de risco e características associadas à gravidade dos acidentes.

---

## 🎯 Objetivos

* Identificar os municípios com maior concentração de acidentes.
* Analisar as principais causas e tipos de acidentes.
* Avaliar fatores associados à gravidade e fatalidade das ocorrências.
* Investigar o impacto das condições meteorológicas e características das vias.
* Produzir indicadores que possam auxiliar ações de prevenção e segurança viária.

---

## 📂 Estrutura da Análise

### Frequências e Rankings

Foram analisadas as distribuições de:

* Municípios com maior número de acidentes.
* Principais causas dos acidentes.
* Tipos de acidentes mais frequentes.
* Classificação das ocorrências.
* Tipo de pista.
* Traçado da via.
* Uso do solo.

### Séries Temporais

Análise da evolução mensal de indicadores como:

* Índice de gravidade.
* Percentual de acidentes graves.
* Impacto das condições meteorológicas ao longo do ano.

### Análises Bivariadas

Foram realizados cruzamentos entre variáveis para identificar fatores associados à fatalidade dos acidentes, incluindo:

* Unidade Federativa (UF).
* Causa do acidente.
* Tipo de acidente.
* Condição meteorológica.
* Uso do solo.
* Combinações de fatores críticos.

---

## 📊 Principais Resultados

### Principais Causas dos Acidentes

| Causa                                    | Participação |
| ---------------------------------------- | ------------ |
| Ausência de reação do condutor           | 16%          |
| Reação tardia ou ineficiente             | 15%          |
| Acessar via sem observar outros veículos | 10%          |
| Velocidade incompatível                  | 6%           |
| Ingestão de álcool                       | 5%           |

### Tipos de Acidente Mais Frequentes

| Tipo                      | Participação |
| ------------------------- | ------------ |
| Colisão traseira          | 20%          |
| Saída de leito carroçável | 14%          |
| Colisão transversal       | 13%          |
| Colisão frontal           | 7%           |
| Atropelamento de pedestre | 4%           |

### Classificação dos Acidentes

* Com vítimas feridas: **77%**
* Sem vítimas: **15%**
* Com vítimas fatais: **7%**

### Uso do Solo

* Não urbano: **57%**
* Urbano: **43%**

---

## 🔍 Fatores Associados à Fatalidade

A taxa média de acidentes fatais observada na base foi de **7,2%**.

### Estados com maiores taxas de fatalidade

| Estado   | Taxa Fatal |
| -------- | ---------- |
| Maranhão | 19%        |
| Pará     | 17%        |

### Causas mais críticas

| Causa                  | Taxa Fatal |
| ---------------------- | ---------- |
| Pedestre na pista      | 41%        |
| Transitar na contramão | 30%        |

### Tipos de acidente mais letais

| Tipo                      | Taxa Fatal |
| ------------------------- | ---------- |
| Atropelamento de pedestre | 30%        |
| Colisão frontal           | 29%        |

---

## 🌦️ Condições Meteorológicas

As maiores taxas de fatalidade foram observadas nas seguintes combinações:

| Condição         | Fase do Dia | Taxa Fatal |
| ---------------- | ----------- | ---------- |
| Nevoeiro/Neblina | Anoitecer   | 25%        |
| Vento            | Pleno dia   | 15%        |
| Nevoeiro/Neblina | Plena noite | 15%        |

Esses resultados indicam que condições de baixa visibilidade aumentam significativamente o risco de acidentes fatais.

## 📌 Conclusões

Os resultados demonstram que:

* Colisões traseiras e transversais concentram grande parte das ocorrências.
* Atropelamentos de pedestres e colisões frontais apresentam os maiores índices de fatalidade.
* Maranhão e Pará registram taxas de mortalidade significativamente superiores à média nacional.
* Áreas não urbanas apresentam maior severidade nos acidentes.
* Condições meteorológicas adversas aumentam o risco de fatalidade.
* A combinação de múltiplos fatores de risco potencializa significativamente a gravidade das ocorrências.

Essas informações podem auxiliar na definição de estratégias de fiscalização, educação para o trânsito e planejamento de políticas públicas voltadas à redução da mortalidade nas rodovias brasileiras.
